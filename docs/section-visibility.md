# Thumbnails and section visibility

In **Content → Itineraries**, use **Thumbnail image (listing cards)** for the
homepage, package lists, search results and related-trip cards. **Main itinerary
photo** and **Gallery photos** control the images inside the itinerary. Existing
listing images have been copied into the new thumbnail fields. When a new trip
has no thumbnail, its main image is used as a fallback.

Open **Website → Page Visibility** to hide sections for all itineraries, Tour
Packages, FAQ, Contact Us and content pages, or the shared website header/footer.
In each editor, open the section's **•••** menu and choose **Hide section** or
**Show section**. Array/block fields include the option in the same menu as
Copy Field and Paste Field. Other editable sections have a menu beside their
heading. The old separate per-page visibility panel is no longer displayed.
A section is shown only when both its shared default and individual setting
are on. Hidden trip sections are removed from navigation links too.

In **Content → Pages**, use the menus beside the introduction, navigation and
Page sections. Individual blocks retain their own **Show this section** checkbox.
In **Website → Home Page**, use the section heading or array's menu; both control
the same section. Save (or publish the itinerary/page) to apply the change.

Visibility changes leave the saved content and uploaded images in the CMS.
